Deutsch Lernen AI

Deutsch Lernen AI is a personal, locally operated tool for managing educational German-language content on YouTube.

What it does today

The application uses Google OAuth to access the channel owner's YouTube Analytics reports and read video metadata. It creates local reports for channel analysis. It does not automatically publish videos in the current version.

Future features

Planned features include creating educational videos, scheduling uploads, and using analytics to guide new content. Any additional YouTube permissions will be requested separately when needed.

Access and control

The application is operated by its owner. It does not provide a public sign-up service. Google permissions can be revoked at any time in Google Account connections.
